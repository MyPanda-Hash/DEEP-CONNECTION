# DEEP-CONNECTION — MES 系统通用设计资产库(AI Agent 参考实现库)

> **用途**:其他项目(不限 MES)开发时,agent 读取本库即可**按文档复现**这些系统级通用能力。
> 内容来自 **YINJIA-MES**(C:\INCER\YINJIA-MES)与 **light-mes**(E:\INCER\light-mes)两个生产级项目的
> 提炼,双实现互相印证。**给的实现原则:先读文档 → 按契约实现 → 用示例代码校验。**

## 给 Agent 的使用指引

1. **先读 `docs/00-系统通用设计盘点.md`** —— 全部能力清单(A-H 类 + 差异表),快速定位某项能力在哪类。
2. **读对应专题文档** `docs/0X-*.md` —— 每篇含:设计意图 / 契约(接口、数据结构) / 关键实现位置(两个项目) / 复现步骤。
3. **对照代码** `snippets/` —— 从两项目提取的关键实现(标注出处与文件路径),可直接参照或整体移植。
4. **对照表结构** `schemas/` —— 核心表 DDL(yj_panel/yj_field/翻译表/状态表/占用表/列偏好表…),建表即用。
5. 每篇文档末尾的「验收锚点」= 实现后必须通过的最小动作。
