# 02 界面通用能力(列表/表单/弹窗/输入类)

> 来源:YINJIA-MES(`C:\INCER\YINJIA-MES`)+ light-mes(`E:\INCER\light-mes` 为真源)。
> 本文给 agent 的结论:以下能力全部**随面板自动具备**,无需按面板写业务代码。
> 与 `docs/00-系统通用设计盘点.md` B 类对应;底表脚本为 `frontend\src\core\views\PanelxList.vue`(两项目同构)。

## 0. 通用前提:前端动作分派表(所有弹窗/流程的入口)

`PanelxList.onButton(action)` 按 `buttonName`(中文数据键,不译)统一分派,新增 UI 功能=往这张表加分支:

| action | 处理 |
|---|---|
| 查询/查找 | search();列头筛选、高级筛选、查询方案作用于结果集 |
| 扫描填单 | 打开 `ScanFillDialog`(OCR) |
| 导出 | 报表=整表 CSV(`exportReport`);单据=当前明细页签 CSV(`exportDetail`) |
| 打印/预览 | `window.print()` |
| 表格调整 | 列自定义弹窗(§1) |
| 复制 | 取 `getFormDescriptor` → 去编号/状态/行 id → callButton('保存') 生成新草稿 |
| 放弃/恢复 | 丢弃内联修改,重载最近一次保存数据 |
| 选单/选X | 有 `selectConfig` 则走选单弹窗(已审核源+占用过滤);无配置灰态占位 |
| 新增/新增流程 | 后端 callButton('保存') 建新草稿(自动编号+当天日期),列表页内联填写 |
| 修改 | 打开 `VoucherFormDialog`(§5) |
| 导入 | 打开 `ImportDialog`(§7) |
| 保存/保存为草稿/保存新增 | `saveInlineDraft` 落库 |
| 灰色动作(@disabledActions) | 点击直接忽略,不执行不弹提示 |

## 1. 表格列自定义(排序/栏名/显隐)

**契约**:工具栏「更多→表格调整」打开列配置表(每行:列名/顺序▲▼/显示勾选/栏名别名)→ `POST /api/px/saveColumnPrefs {panelCode, columns:[{label\|name, alias, visible}]}` → 刷新按新列序/别名/显隐渲染。数据键永远中文列名,别名仅显示层。

**双实现差异**:
- **YINJIA(全局/元数据级)**:`PanelxList.openColPrefs()` 内嵌弹窗(无独立组件)→ `service\PanelConfigService.saveColumnPrefs()` → **UPDATE yj_field SET seq=(i+1)*10, alias, visible** WHERE panel_code+col_name → `registry.reload()`。本质是**改面板字段定义**:所有用户共享,别名/顺序写回字段元数据——个人偏好污染共享定义。
- **light-mes(用户级,推荐)**:`core\views\ColumnPrefsDialog.vue`(独立弹窗:顺序/显示/别名三列 + 恢复默认二次确认)→ `service\PxService.saveColumnPrefs(panelCode, userName, columns)`:**DELETE + INSERT px_column_pref(panel_code, owner, col_name, seq, alias, visible, update_by)**(owner=登录用户,空数组=恢复默认删行,栏名别名重复报 400);读取出口 `getPanelConfig(panelCode,userName)` 经 `applyColumnPrefs` 重排/过滤 gridTabs.columns 并注入 `metadata.columnAliases`/`metadata.columnPrefs`(含隐藏列全量清单,供弹窗初始化与"未收录列按原序追加默认显示");**绝不写回 panel_config.config**(4 个 Registry 启动时无条件覆盖 config 列,见 01)。

**建议:选用户级(light-mes 方案)**,见 00 B1a。单机/单用户小仓可接受 Y 方案(省一张表,但改字段定义语义重)。

**复现要点**:
- 弹窗初始化数据源 = `metadata.columnPrefs`(首选,含隐藏列)→ 无则 `gridTabs[0].columns` 映射;
- 显示别名用 `columnAliases`(值=显示名,键=数据键);`displayToKey` 供反向还原(查询条件/导出用数据键);
- 保存成功后必须刷新面板配置(vue 侧清 `cfgCache` 重 load),否则列序不生效。

## 2. 列头点击筛选 / 高级筛选 / 查询方案

**契约**:
- **列头筛选**:点击列头出现小输入框(`filterColProp`),`colFilterText[prop]` 对当前列表做 **includes 客户端过滤**(不区分大小写;多个列头条件 AND;非空条件显示 `清理×` 角标;Escape 清除);
- **高级筛选**:弹窗内 `advFilters:[{field, op, value}]` 行式条件,9 操作符 `contains/eq/ne/gt/lt/ge/le/empty/notEmpty`;数值型可比较时按数值(忽略千分位),否则字符串比较;`applyAdvFilters` 只取有效条件(空值/空串不参与)且条件间 AND;
- **查询方案**:把当前 `condition + advFilters` 存入 **localStorage**(按面板键隔离),支持保存/覆盖/应用/删除,方案名可带标签(`查询方案`+`高级筛选×N`)。

**关键文件**(YINJIA `core\views\PanelxList.vue`):`toggleColFilter/clearColFilter/hasColFilter/applyColFilters/ADV_OPS/advMatch/advFilters/queryPlans`(方案 keys 用 `plansKey()`);报表面板另走 `core\report\{reportColumnSettings.js,useReportColumns.js}` + `ReportColumnSettingsService`(`/api/px/reportColumnSettings` GET/POST:栏目显隐/表头筛选/排序**后端持久化**,仅报表面板)。

**复现要点**:
- 列表筛选/高级筛选是**纯前端过滤**(不重发后端查询),快且零接口;
- 报表列设置才走后端持久化(跨设备);
- 查询方案入 localStorage 不入库(换机不带走属预期)。

## 3. 页签系统(多单据页签)

**契约**:顶栏下页签条,`path+query` 定位;打开/关闭/关闭其他/关闭全部;首页「我的桌面」affix 常驻;关闭激活页签自动切相邻页签,全关回 `/dashboard`;同一路径再次打开**更新标题与 query**(如单据表单 `?code=`),但忽略「X-新增」占位页签的覆盖请求(`isNewReq && !exIsNew`);路由变化 `sync(route)` 回写 `?code=` 参数,切页签回来单据不丢。

**关键文件**:`stores\tabs.js`(open/sync/close/closeOthers/closeAll)+ `layout\TabsBar.vue`。light-mes 版本另有「更多 ▾」按钮(全部页签快速查找);YINJIA 精简版无。

**复现要点**:
- tab 身份 = path+query;打开单据页签时 title 带单号(「生产加工单-MO-xxx」);
- 页签关闭走路由(router.push),必须能触发路由守卫——未保存守卫(§4)依赖这一点;
- 重复打开同面板:更新 query 而非叠页签。

## 4. 未保存离开守卫(保存/不保存/取消)

**契约**:草稿态存在未保存修改时,离开本页(菜单切换/页签关闭/后退)弹三态确认:
- **保存** → 走「保存」按钮路径(`saveInlineDraft({silent:true})`)落库后放行;
- **不保存** → 本次新增且未保存过的**撤回整单**(走「删除」按钮路径:软删+留痕(yj_doc_status cancel_by/cancel_at)+ `form_flow_link` 占用释放);修改既有草稿仅放弃修改(不删单);
- **取消** → 留在本页(页签可能已被关,`restoreCurrentTab()` 补回)。

刷新/关浏览器另挂 `window.beforeunload` 原生确认兜底。

**关键实现**(YINJIA `PanelxList.vue`,2026-09-01 规范):
- 脏判定 = 变更钩子 `markInlineDirty()`(表头/明细控件 @change 置脏)+ **快照对比兜底**(`savedSnapshot` = load/保存成功后 `JSON.stringify` 基线;`hasUnsavedChanges()` 两者或);
- 路由守卫**同步 `return false` 拦截**(`onBeforeRouteLeave`),弹窗在守卫之外(`askUnsavedLeave` 模板弹窗,避免在守卫内 await 弹窗的竞态——hash 已改/页签已关),选择后置 `leaveConfirmed` 放行一次或执行挂起的 `pendingAction`(翻页/点行切单);
- `guardAsking` 防重入;弹窗用模板组件而非命令式 ElMessageBox(导航守卫上下文中命令式弹窗不渲染)。

**复现要点(三个坑)**:
1. 守卫必须**同步**拦截——导航守卫里 await 弹窗有竞态;
2. 快照在 load/保存后**必须重打**(快照错位→恒脏→守卫/beforeunload 卡死);
3. 「不保存+新增」撤回路径要与「删除」按钮同一实现(留痕+释放占用),不要另起一套。

## 5. 表单弹窗(双击/修改行)

**契约**:列表行双击(或「修改」按钮)→ `VoucherFormDialog`(`:panel-code :code` 两个 props,内嵌完整 `PanelxForm`:表头+明细+底栏按钮+审批)→ 保存成功 emit `saved` 刷新列表;已审核单据自动只读提示。

**关键文件**:两项目同 `core\views\{VoucherFormDialog.vue, PanelxForm.vue}`;数据口径 = `getFormDescriptor(panelCode, code)` 全量,可编辑性按 metadata+权限矩阵。

**复现要点**:弹窗组件**零业务**——面板+单号即完整单据;保存 = callButton(buttonName='保存');关闭时不落库(丢弃),如需要可挂未保存守卫。

## 6. 参照字段双模(≤20 下拉 / >20 弹窗)——已定为系统默认

**契约(零配置)**:表头/查询区参照字段,数据量 **≤20 条=普通下拉**(选项一次取回),**>20 条=弹窗**(搜索+表格选择);数量跨越阈值(增删档案后)由 `refreshRefModes()` 重新判定并自动切换;**明细单元格恒弹窗**。下拉框(字典)字段同规则:`dictModeOf` 按 `fieldOptions().length` 判定,>20 弹窗带搜索。选中参照后整串带回:`refMap` = 同名自动映射 + 同义词映射(如存货"计量单位"→本单"销售单位/单位/生产单位",编码/名称的 材料/产品/物料 异名口径)。

**关键文件**:`PanelxList.vue`(`checkRefMode`/`REF_DROPDOWN_THRESHOLD=20`/`refModeMap`/`loadRefSelectOptions`/`refreshRefModes`/`dictModeOf`/`dictPickVisible`/`onDictPick`)+ `RefPickDialog.vue`;后端 `PanelConfigService.buildRefMap/fieldSpec`(refPanel/refField/displayField/refMap 由 yj_field 行配置);适配器辅助 `engine.refRowCount/refSelectOptions/queryRefRows/refColumns`(见 01 REQUIRED_METHODS)。

**复现要点**:
- 模式判定=先默认弹窗→异步 `refRowCount` → 可能切换下拉(渲染期占位后切换);
- 字典模式缓存按面板清理(`resetDictModes`),同名字段跨面板数量可能不同;
- 参照弹窗表格列优先 `refColumns`,其次引用面板网格列,最后 refField/displayField。

## 7. 导入 / 导出

**契约**:工具栏「导入」→ `ImportDialog`(下载模板 → Excel 预览 → 列映射)→ 确认后按字段**追加明细行并自动保存**(导入字段取自配置 `detail.tabs[].fields` 或 `dataSchema.fields`,排除 hidden,**不写死**);「导出」= 报表整表 CSV(`exportReport`)/ 单据当前明细页签 CSV(`exportDetail`),表头用当前显示名(别名/译名)。

**关键文件**:两项目同 `core\views\ImportDialog.vue`;`PanelxList.onButton('导入'/'导出')` 分支;后端文件服务(模板/解析)见 00 F5。

## 8. 扫描填单入口(OCR)

**契约**:面板随元数据自动具备「扫描填单」按钮 → `ScanFillDialog` 上传图片 → OCR(`OcrScanService/AliyunOcrGateway/OcrFormMapper`)按字段映射回填当前单据;凭证未配置降级提示不报错。深读见 00 F1 与 06 篇。

## 9. 表格右键菜单 / 批量操作

**契约**:明细网格 `@contextmenu` → 自绘 `ctx-menu`(定位/复制到剪贴板/从剪贴板粘贴/另存为EXCEL模板/批量修改/销售订单查询/存货中心/更多),菜单集按面板裁剪(材料类面板插入「现存量提取」);另有 `Ctrl+V 列粘贴`(按列宽对齐命中列)、批量修改(选中多行统一改值)、明细列合计行。

**关键文件**:`PanelxList.vue`(`ctxItems/iconA/iconB/onCtx/closeCtx/copyActive`;ctx 菜单在模板内联,`@contextmenu.prevent.stop` 全路径拦截)。

## 10. 验收锚点

- 调整列显隐/别名/顺序:用户级方案仅影响本人且刷新保持、恢复默认生效;Y 方案全站生效;
- 列头筛选即时过滤;高级筛选 9 操作符可用;查询方案保存后重开面板可应用;
- 草稿有修改时切换/关闭页签必弹三态;刷新浏览器弹原生确认;
- 双击行弹出完整表单弹窗;参照字段数据量跨越 20 条阈值自动切换下拉/弹窗;
- 任意面板「导入」无需改码即可用 Excel 模板;导出 CSV 列头为当前显示名;
- 整个列表视图不含任何面板专属的 if/else 分支(新面板零代码自愈)。
