# 07 门户与导航（三段式壳 / 飞卡 / 页签 / 顶栏）

> 来源：light-mes（E:\INCER\light-mes，真源 f850839）· YINJIA-MES（C:\INCER\YINJIA-MES）。
> 标注沿用 00 盘点：**[共]** 两项目共有 · **[L]** light-mes 独有 · **[Y]** YINJIA 独有。
> 前置：面板引擎契约见 01；页签/列头筛选等界面能力见 02；多语言见 03。

## 0. 设计意图

MES 外壳是「顶栏 + 左侧导航 + 页签内容区」三段式。本能力的要点是**外壳与业务解耦**：菜单树是纯数据（前端静态 `menuTree` + 后端 `yj_panel` 注册表），面板页面由参数化路由 `/panelx/list/:panelCode` 单路由承载，页签状态与路由深度联动，导航对语言/权限/移动端自适应。复现时直接复用 Vue3 + Element Plus 实现，不重新设计。

## 1. 三段式门户（PortalLayout）

### 契约

- 结构（`PortalLayout.vue`）：`TopBar`（52px）→ `portal-body`：`LeftNav`（184px，折叠 56px）+ `portal-main`（`TabsBar` 36px + `portal-content` 内 `router-view`）。
- 内容区 `<router-view v-slot>` + `<keep-alive :max="20">`：页签页保持状态（筛选/滚动/草稿），20 个上限自动淘汰。
- 路由（`router/index.js`）：面板单路由 `/panelx/list/:panelCode`、`/panelx/form/:panelCode`；`hash` 模式（`createWebHashHistory`）；`meta.requireAdmin` 守卫重定向 `/dashboard`。
- 路由联动双 watch：`route.path` → `tabs.setActive` + `findMenuByPath` 未开则 `tabs.open`；`route.fullPath` → `tabs.sync`（见 §3）。
- 移动端（≤768px）：`LeftNav` 变抽屉（`app.mobileNav` + `nav-mask` 遮罩）；`app.maxContent` 隐藏左栏（内容区最大化）。
- 根节点 `:class="{ dark: app.dark }"`；`onMounted` 里 `Promise.allSettled([user.fetchUserInfo(), user.fetchFactories()])` 刷新本地缓存，`!app.initDone` 时自动打开 `InitWizard`。

### 关键文件

- `frontend/src/layout/PortalLayout.vue`（两项目 112–115 行同构）
- `frontend/src/router/index.js`（YINJIA 55 行；`flatMenus()` 自动挂载业务菜单）
- `frontend/src/stores/app.js`（`collapsed/dark/menuMode/maxContent/mobileNav/helpTab/initWizardVisible`）

### 复现要点

1. 路由集中：除 dashboard/看板/系统页外，全部面板页走参数化路由，禁止每面板一个组件。
2. `keep-alive` 的 `max` 必须与页签列表设计同源，否则关闭页签后状态错乱。
3. 登录信息缓存在 localStorage 的目的是快速启动，挂载后必须拉服务端覆盖（权限/工厂变更）。

## 2. 左侧导航（折叠 / 树 / 飞卡）

### 契约

- 菜单树 `menuTree`（`business/menus.js`）：节点 `{ code, title, icon, path?, children?, panelCode?, operationName? }`；有 `path` 即可跳转；`filterMenuTree(raw, user.visiblePanels, user.isAdmin)` 按角色过滤（操作员仅见被授权面板）。
- 树交互：一级分组点击展开/收起（`expandedGroup`；`menuMode==='flat'` 平铺全展开）；折叠态点击分组自动展开。
- 飞卡 FlyCard：一级分组或模块悬停 → `.fly-card` 浮层（`left:100%`、`min-width:520px`、`max-width:min(820px, calc(100vw - 210px))`、`max-height` 由 `updateCardPosition` 按可视高度计算，`top` 自动上移、`--fly-pointer-top` 精确指向所选项）；`@mouseleave="closeCard"` 关闭。
- 分列：`cardColumns` computed + `flattenCardItems`（叶子递归打平，`depth` 缩进、父节点加粗）——**列按子分类分列，叶子合并进所属列**。
- 功能区 `.func-zone`：折叠 / 单据查询 / 新增单据（弹窗 `billMatches` 关键字过滤；新增走 `{ new: 1 }` 参数）。
- [L] 非中文语言时 `watch localeStore.current` → `ensureDict` 预取全部菜单标题词条（库表词典/机翻）。

### 列策略示例（YINJIA `LeftNav.vue` 的 `cardColumns`；light-mes 仅通用分支）

| 一级 | 列数 | 分支 | 列组成 |
|---|---|---|---|
| 研发管理 `rd` | 4 | 特例 `m.code==='rd'` | 「研发管理」列（无子分类叶子合并：立项申请/项目实施计划/项目进度查询）+ 数据记录表/产品文件/实验室使用记录表 3 列 |
| 智能供应链 `scm` | 5 | 通用（首子含子分类） | 销售管理 / 采购管理 / 库存核算 / 库存明细 / 库存统计 |
| 生产制造 `mfg` | 3 | 特例 `m.code==='mfg'` | 取 `prod.children`：单据 / 明细表 / 统计表 |
| 基础档案 `base` | 4 | 通用分支 | 基础数据 / 物料及价格 / 生产 / 财务 |
| 全叶子模块 | 1 | 通用（无子分类） | 所有叶子合并一列竖排 |

### 关键文件

- `frontend/src/layout/LeftNav.vue`（两项目；`openCard/closeCard/updateCardPosition/cardColumns/flattenCardItems` + 移动端 `mStack` 层级堆叠）
- `frontend/src/business/menus.js`（YINJIA：`menuTree/flatMenus/filterMenuTree/findMenuByPath`）

### 复现要点

1. 先建 [一级分组 → 子分类 → 叶子] 三层菜单，再给不规则模块写 `cardColumns` 特例（rd 叶子归并、mfg 取生产管理的子分类），不要期待一个通式覆盖所有模块。
2. 飞卡定位三件套：以锚点为中心、按 `navRect` 可视高度封顶（≥180px）、空间不足自动上移且指针仍指向原项。
3. 折叠/移动端分级降级：折叠只剩图标（宽度 184→56，tooltip 出标题）；移动端整树换 `mStack` 下钻堆叠，不进抽屉不弹卡。

## 3. 页签系统（防污染 open / query 同步关闭）

### 契约

- `stores/tabs.js` state：`{ tabs: [{title, path, query, affix}], active }`；固定页签「我的桌面」`/dashboard`（`affix:true`，不可关）。
- `open(menu)`：同 `path` 已存在 → 更新 `title/query` 并激活；不存在 → push。
- **防污染规则**（两项目同）：`title` 以「-新增」结尾视为新增请求；已打开具体单据页签（非「-新增」）时，忽略「X-新增」请求——只激活，**不覆盖已有标题与 query**。
- `sync(route)`：路由 `fullPath` 变化时只把 `tab.query` 同步为当前 `route.query`（恢复 `?code=`/`?id=` 单据参数，修复「生单后切回数据丢失」）；**不覆盖标题**——标题由打开方设置（如「生产加工单-MO-xxx」）。
- `close(path)`：跳过 affix；关闭的是活动页签时 `active` 取相邻（索引 `Math.min(idx, len-1)`，左优先）。
- `closeOthers/closeAll`：只保留 affix；`closeAll` → `router.replace('/dashboard')`。
- `TabsBar.closeAndGo(path)`：关闭当前页签后，跳到新 `active` 页签并**携带其 `query` 恢复**（`router.replace({ path, query })`）。
- 页签标题渲染走 `tt(t.title)`，语言切换即时重渲。

### 关键文件

- `frontend/src/stores/tabs.js`（两项目 55 行完全同构）
- `frontend/src/layout/TabsBar.vue`（活动高亮/关闭/右键菜单：刷新·关闭·关闭其他·关闭全部；[L] 更多按钮）
- `frontend/src/layout/PortalLayout.vue`（路由 watch 联动）

### 复现要点

1. 防污染判据用**标题后缀约定「-新增」**而非路由参数——新增/编辑共用同一路径，必须一个约定区分。
2. 凡带参跳转（生单 `?code=`、表单 `?id=`）由打开方同时写 `title + query`；页签切换恢复一律 `router.push({ path, query: t.query })`。
3. 关闭逻辑只走 store actions（关单个/其他/全部），禁止组件自行 `splice`，保证 affix 与激活页签切换行为一致。

## 4. 顶栏（工厂切换 / 语言 / 通知 / 帮助 / 设置）

### 契约

- 左：移动端汉堡 + Logo + **工厂（账套）切换** [共]：`user.factories/factoryName/switchFactory(f)`，Refresh 图标 `fetchFactories()` 刷新；数据按工厂隔离。
- 中 [Y]：账号/认证状态·企业/登录日期/服务到期（移动端隐藏）。
- 右：语言下拉（`localeStore.available/set`，Alt+L 循环，按用户记忆 `yj_user.locale`）；内嵌全局搜索（按 `title/fullTitle/panelCode/path` 匹配，≤10 条）；更新公告（`apiGetNotices('notice')` + `new` 角标）；`NoticeCenter`（待办/消息/预警）；全屏；帮助下拉；用户下拉。
- **帮助下拉** [Y]：`docs`→`app.openHelp('help')`、`ai`→`app.openHelp('knowledge')`、`guide`→`openInitWizard()`、`about`→关于弹窗；帮助面板 [L] 为右滑 `el-drawer`（rtl、380px、页签式 `dynamic/message` + 未读角标）。
- **初始化向导** `InitWizard` [L]：三步（选择行业细分&经营业态 → 行业特性选择&设置 → 完成初始化设置）；首次登录自动弹出（`!app.initDone`），`mes_init_done` 持久化，可跳过（`skip` 仅标记完成）。
- **界面设置** `UiSettingsDialog` [L→Y]：菜单模式（手风琴/平铺 `mes_menu_mode`）· 侧边栏默认折叠（`mes_collapsed`）· 暗色模式（`mes_dark`，切 `html.dark`）；提示「设置实时生效并保存到本机浏览器」。
- **工作台设置** `DeskSettingsDialog` [L]：快捷入口（新建加工单/快速报工/生产看板）+ 内容卡片（KPI 指标卡/生产进度/我的待办）→ `mes_desk_settings`。
- 用户下拉：组织架构/使用权限查看（admin → `/sys/org`、`/sys/usage`）、账号管理、修改密码、界面设置、换肤（暗色）、工作台设置、初始化向导、退出。

### 关键文件

- `frontend/src/layout/TopBar.vue`（组合 `UiSettingsDialog/DeskSettingsDialog/NoticeCenter`）
- `frontend/src/layout/{UiSettingsDialog,DeskSettingsDialog,HelpPanel,InitWizard,NoticeCenter}.vue`
- `frontend/src/stores/{user,locale,app}.js` + `core/request.js`（`Authorization: Bearer`）

### 复现要点

1. 工厂切换 = 数据隔离上下文切换：`factory/list` 匿名可用（登录页先选厂），登录后顶栏可切换/刷新。
2. 语言切换三处联动：EP 组件 locale（`el-config-provider` 响应式）、i18n 重渲、面板配置按 Accept-Language 重生成（见 03/09）。
3. 设置项全部实时生效 + localStorage 持久化，键名统一前缀 `mes_`（`mes_collapsed/mes_dark/mes_menu_mode/mes_desk_settings/mes_init_done`），按设备记忆、不进服务端。

## 5. 验收锚点

- 悬停任一一级分组，1 秒内出现多列飞卡；列数与列策略示例表一致（rd=4 / scm=5 / mfg=3 / base=4）。
- 已打开具体单据页签后再用「-新增」打开同路径：原标题与 query 不被覆盖。
- 生单跳转 `?code=` 后切走再切回，列表/表单数据仍在；`keep-alive` 下滚动/筛选状态保留。
- 关闭全部页签回到「我的桌面」，affix 页签无关闭按钮且不可关。
- 切换语言（Alt+L）后导航/页签/顶栏文案即时切换；暗色模式刷新保持。
- 首次登录自动弹初始化向导，取消后不再自动弹；从用户下拉可再次打开；工作台设置保存后回到「我的桌面」生效。
